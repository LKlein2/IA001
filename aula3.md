# Aula 3 — Bibliotecas para Visualização de Dados e Dashboards

## Bibliotecas de Visualização em Python

A aula apresentou diferentes bibliotecas para visualização de dados em Python, destacando suas características e diferentes abordagens:

* **Matplotlib:** biblioteca fundamental para criação e customização de visualizações.
* **Seaborn:** voltada para visualização estatística, integrada ao ecossistema Python.
* **Altair:** utiliza uma abordagem declarativa para especificar visualizações a partir dos dados.
* **Plotly:** permite criar visualizações interativas.
* **Folium:** voltada para visualizações e mapas geoespaciais interativos.

## Dashboards

Dashboards permitem combinar dados e visualizações em interfaces interativas para exploração, acompanhamento e comunicação de informações.

A aula apresentou ferramentas **No-Code/Low-Code**, como Tableau, QlikSense, ArcGIS e Power BI, além de soluções desenvolvidas em Python.

Entre os frameworks para dashboards em Python, destacam-se:

* **Dash:** voltado à criação de aplicações web interativas para análise de dados.
* **Streamlit:** facilita a transformação de scripts e análises em aplicações web interativas.

## Abordagens de Visualização

As bibliotecas podem utilizar diferentes formas de construir visualizações. Abordagens **imperativas** especificam como os elementos devem ser construídos, enquanto abordagens **declarativas** descrevem o que deve ser representado a partir dos dados.

## Ideias-chave

* Existem diferentes ferramentas para diferentes necessidades de visualização.
* A escolha da biblioteca depende do objetivo da análise e do tipo de visualização desejada.
* Bibliotecas podem ser utilizadas para visualizações estáticas, estatísticas, interativas e geoespaciais.
* Dashboards permitem transformar análises em aplicações interativas.
* As diferentes ferramentas são complementares e podem ser combinadas conforme o contexto.
